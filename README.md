# BroCode Platform

BroCode is a full-stack coding platform focused on practicing Data Structures and Algorithms in a structured, competitive, and collaborative environment.
The platform allows developers to create or join coding groups, participate in timed problem-solving sessions, monitor progress, and analyze their performance over time. It also integrates LeetCode statistics so users can showcase their coding activity and maintain consistency in practice.
The goal of BroCode is simple: remove friction from DSA practice and turn it into a social and competitive experience where developers improve together.
Built using a modern web stack, the platform focuses on performance, real-time interaction, and a clean developer experience.
